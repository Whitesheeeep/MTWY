Inventory 模块结构

UI / MVVM

InventoryBarView / InventoryBagView 前端显示、控件实例、点击转发。
InventoryBarViewModel / InventoryBagViewModel UI 状态、ViewData、用户意图入口。
InventorySlotViewData 面向 View 的显示数据。

Core

InventoryManager 对外入口，管理 Bar / Bag，触发变更事件。
InventoryScheduler 协调 Bar 与 Bag 之间的移动、拆分、合并和拾取分配。
InventoryData / InventorySlotData 背包数据和槽位数据。
InventoryChangeSet 记录受影响槽位，用于局部刷新。

Runtime / Test

ItemPickupCollector2D 场景拾取行为，将物品提交到 InventoryManager。
InventoryOdinTester Editor 下手动触发生产接口进行验证。

普通拾取数据流

碰撞 Item
->
ItemPickupCollector2D
->
InventoryManager.AddItem
->
InventoryScheduler
->
Bar 优先
->
剩余进入 Bag
->
Changed 事件刷新 UI
